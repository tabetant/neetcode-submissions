## How it's organized

Every submission lands in its own file under a topic folder, indexed by problem and submission number:

```
<topic-folder>/
  <problem-id>/
    submission-0.<ext>   # first accepted attempt
    submission-1.<ext>   # later iterations as I revisit
```

Example:

```
Data Structures & Algorithms/two-integer-sum/submission-0.py
Data Structures & Algorithms/binary-search/submission-0.ts
```

Each subsequent attempt on the same problem appends a new file rather than overwriting, so the progression from a brute-force pass to an optimized one is preserved.

## How the sync works

1. NeetCode is connected to this GitHub account at [neetcode.io/profile/github](https://neetcode.io/profile/github).
2. Submissions push automatically when accepted (configurable by status).
3. Past submissions can be backfilled in bulk from the GitHub settings page.
